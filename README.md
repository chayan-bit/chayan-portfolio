# Chayan Aggarwal — Portfolio

A light, motion-led portfolio spanning core AI/ML, agentic AI, and low-level
systems work.

## Local development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm run build
npm audit
```

The site is a single React page built with Vite and Framer Motion. Vercel can
deploy it with the default Vite settings (`npm run build`, output directory
`dist`).
